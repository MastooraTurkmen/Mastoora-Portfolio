Project Overview

The Paper Airplanes Educational Website is an interactive learning platform designed to provide free programming resources and tutorials for learners worldwide. Built collaboratively by three developers from Pakistan, India, and Afghanistan, the project reflects teamwork across borders and a shared mission to make education more accessible. With its clean, modern design and responsive interface, the platform offers an engaging and user-friendly learning experience. Developed using React, Framer Motion, and modern design principles, the website emphasizes smooth animations, intuitive navigation, and structured educational content.

The focus on accessibility and responsiveness ensures that users can benefit from the platform across different devices and screen sizes. This project not only showcases my frontend development and design skills but also demonstrates my ability to collaborate effectively in a global, cross-country team. It highlights strong communication, version control, and project management practices while delivering a meaningful solution that promotes online education.
