Project Overview

The Tannglege Engen AS Website is a professional dental clinic website developed for my Norwegian client to showcase their services, team, and contact information. The platform provides patients with an easy way to learn about the clinic, explore available treatments, and get in touch for appointments. Its clean and modern design ensures accessibility and user-friendliness, reflecting the professional image of the dental practice.

Built using Next.js, React, Tailwind CSS, DaisyUI, and Framer Motion, the website features smooth animations, responsive layouts, and optimized performance for all devices. It also integrates Google Maps for location accessibility and highlights the clinic’s experienced dental team. The codebase is well-structured, ensuring scalability and maintainability for future updates.

This project demonstrates my ability to build customized client-focused solutions, balancing both aesthetic design and technical functionality. It also reflects my skills in delivering real-world projects for international clients with attention to detail and professionalism.
